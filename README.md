# Workout Diary — Офлайн-дневник тренировок (PWA)

Полноценное мобильное прогрессивное веб-приложение (PWA) для записи и отслеживания силовых и кардио-тренировок в спортзале, дома или на улице.

Приложение спроектировано по принципу **Offline-First**: данные хранятся локально на устройстве в **IndexedDB** (через **Dexie.js**), работают без интернета после первичного открытия, не требуют регистрации, аккаунтов или сервера.

---

## 🚀 Основные возможности

- **Mobile-First UX**: крупные элементы управления, удобные поля ввода веса и повторений, навигация одной рукой в спортзале.
- **Офлайн-режим (PWA)**: Service Worker кэширует оболочку и ресурсы приложения. Статус сети и готовности отображается на панели.
- **Быстрый ввод подходов**:
  - Поддержка дробных весов (например, `22.5 кг`).
  - Быстрое дублирование предыдущего подхода одной кнопкой («Копировать подход»).
  - Добавление заметок к конкретному подходу или ко всей тренировке.
- **Повторение прошлых тренировок**: возможность скопировать структуру любой завершённой тренировки в новую запись с новыми идентификаторами, не изменяя исходник.
- **Встроенный локальный каталог**:
  - 14 базовых популярных упражнений (Жим лёжа, Приседания, Становая тяга, Подтягивания, Планка, Бег и др.).
  - Добавление собственных пользовательских упражнений с указанием категории и снаряда.
  - Поиск и фильтрация по группам мышц.
- **Аналитика и графики прогресса**:
  - Локальный расчёт общего тоннажа тренировки (вес × повторения для силовых сетов).
  - Раздельный учёт силовых (кг) и кардио/статических упражнений (время, дистанция).
  - График роста рабочего веса по выбранному упражнению.
  - Расчёт одноповторного максимума (1RM) по формуле Бжицки (Brzycki).
  - График объёма нагрузки по тренировкам.
- **Резервное копирование (JSON)**:
  - Экспорт всех данных в JSON-файл в память устройства.
  - Импорт с проверкой структуры и версионирования.
  - Транзакционное восстановление базы данных с подтверждением пользователя.
- **Темы оформления**: поддержка тёмной, светлой и системной темы.
- **Безопасность и приватность**: никаких сторонних SDK, трекеров, аналитики и передачи личных данных в сеть.

## 🛠 Технологический стек

- **Фреймворк**: React 18 (TypeScript, Strict Mode)
- **Сборщик**: Vite 6
- **Локальная база данных**: IndexedDB + Dexie.js 4 + dexie-react-hooks
- **PWA & Offline**: vite-plugin-pwa, Workbox, Web App Manifest
- **Графики**: Recharts
- **Иконки**: Lucide React
- **Тестирование**: Vitest, React Testing Library, JSDOM, fake-indexeddb
- **Стили**: CSS Variables (Dark / Light mode), Mobile Viewport Optimization

## 📦 Установка и запуск

### 1. Установка зависимостей
```bash
npm install
# или на Windows PowerShell при ограничении скриптов:
npm.cmd install
```

### 2. Запуск в режиме разработки (Hot Reload)
```bash
npm run dev
# или:
npm.cmd run dev
```
После запуска откройте в браузере локальный адрес: `http://localhost:5173`.

### 3. Запуск тестов
```bash
npm test
# или:
npm.cmd test
```

### 4. Production-сборка
```bash
npm run build
# или:
npm.cmd run build
```
Готовые оптимизированные файлы для развёртывания будут созданы в папке `dist/`.

Для предварительного просмотра собранного PWA:
```bash
npm run preview
# или:
npm.cmd run preview
```

## 🧪 Инструкция тестирования офлайн-режима

1. Запустите production preview: `npm run preview`.
2. Откройте приложение в Google Chrome или Edge: `http://localhost:4173`.
3. Откройте инструменты разработчика (**F12** или **Ctrl+Shift+I**).
4. Перейдите на вкладку **Application** (Приложение) -> **Service Workers**:
   - Убедитесь, что Service Worker установлен и активен (`status: activated and is running`).
5. Перейдите во вкладку **Application** -> **Storage** -> **IndexedDB**:
   - Найдите базу `WorkoutDiaryDB` со всеми таблицами (`workouts`, `exercises`, `sets`, `catalog`).
6. Перейдите на вкладку **Network** (Сеть) и в выпадающем списке троттлинга выберите **Offline** (Офлайн).
7. Обновите страницу (**Ctrl+R** или **F5**):
   - Страница мгновенно загрузится из кэша Service Worker.
   - В верхнем правом углу появится ненавязчивый индикатор `Офлайн`.
   - Создайте новую тренировку, добавьте упражнения и подходы, нажмите «Сохранить».
   - Перейдите в «Историю» и «Прогресс» — все данные читаются и записываются в IndexedDB без сетевых запросов.

## 📱 Инструкция по установке на смартфон (PWA)

### Android (Google Chrome, Яндекс Браузер, Samsung Internet)
1. Откройте адрес приложения в браузере (через HTTPS).
2. Браузер покажет всплывающее окно «Добавить Workout Diary на главный экран» или нажмите на три точки в верхнем углу меню.
3. Выберите пункт **«Установить приложение»** (или «Добавить на главный экран»).
4. Иконка появится на рабочем столе смартфона и приложение будет открываться в полноэкранном автономном режиме без адресной строки браузера.

### iOS / iPhone (Safari)
1. Откройте адрес приложения в браузере **Safari** (PWA на iOS устанавливаются через Safari).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) в нижней панели Safari.
3. Прокрутите список действий вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Подтвердите название «Workout Diary» и нажмите «Добавить».
5. Приложение запустится с домашнего экрана как нативное iOS-приложение.

## 🌐 Развёртывание на HTTPS-хостинге

Так как приложение является чисто клиентским (SPA / PWA) и не требует сервера:

### Вариант 1. Vercel
1. Установите Vercel CLI: `npm i -g vercel`.
2. В папке проекта выполните команду `vercel`.
3. Сборка выполнится автоматически по команде `npm run build`, каталог вывода — `dist`.

### Вариант 2. Cloudflare Pages
1. Подключите Git-репозиторий в панели Cloudflare Pages.
2. Build command: `npm run build`.
3. Build output directory: `dist`.

### Вариант 3. Nginx / Docker
Пример конфигурации Nginx (`nginx.conf`):
```nginx
server {
    listen 80;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Кэширование статических ассетов PWA
    location ~* \.(js|css|png|jpg|jpeg|gif|svg|ico|webmanifest)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }
}
```

## ⚠️ Известные ограничения и сохранность данных

1. **Политика очистки хранилища браузера (Storage Eviction)**:
   - Данные IndexedDB изолированы для каждого браузера.
   - Если на устройстве критически заканчивается свободная память или пользователь выполняет «Очистить все данные сайта / историю», браузер может очистить локальную базу.
   - **Рекомендация**: в разделе «Ещё» -> «Резервное копирование» регулярно нажимайте **«Экспорт в JSON»** и сохраняйте файл в облако или на диск.
2. **Изоляция между устройствами**:
   - Поскольку у приложения нет серверной базы и авторизации, данные, внесённые на смартфоне, не синхронизируются автоматически с ноутбуком. Для переноса используйте экспорт/импорт JSON.
3. **Требование HTTPS для PWA**:
   - Современные браузеры регистрируют Service Worker только при работе через `https://` (или на `localhost` для разработки).
